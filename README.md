# 🥚 EGGGAME

Telegram-бот на Java, в котором пользователи раз в день получают яйца, из которых вылупляются питомцы разной редкости. Игрок помещает яйца в инкубатор, а затем забирает вылупившихся существ в свою коллекцию. Питомцев можно кормить яйцами, тренировать на арене, водить в вылазки и сражаться ими в пошаговых боях с ботами и другими игроками. Каждый питомец уникален: у него свой вид, редкость, набор способностей и черт характера. По мере прокачки питомцы растут в уровнях, эволюционируют и получают новые способности. Смысл игры — собирать коллекцию питомцев, выбивая всё более редкие экземпляры, и развивать своих питомцев, привязываясь к каждому из них.

Задача 1. Фундамент: бот, БД и базовые функции
Цель: рабочий Telegram-бот с сохранением пользователей.
Команды
- /start — бот выводит приветственное сообщение, регистрация игрока при первом вызове. Выдаёт первое яйцо.
- /help — вывод команд бота и их описание.
- /profile — вывод имени, количества яиц и количества питомцев в коллекции.
- /daily — получить ежедневное яйцо. Доступно раз в 24 часа.
- /incubator — показать состояние инкубатора (пусто / лежит яйцо / вылупился питомец).
- /incubate — положить яйцо из инвентаря в инкубатор. Если слот занят — сообщение об ошибке.
- /hatch — вынуть питомца из инкубатора. Доступно только если яйцо уже вылупилось.
- /pets — вывести список всех питомцев игрока.
- /pet <имя> — вывести карточку конкретного питомца (имя, вид, редкость, описание, картинка).
Неизвестная команда — бот выводит сообщение о неизвестной команде и вызывает /help.
Важно: информация сохраняется при перезапусках бота.
